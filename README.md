# Sketchpad

经典画图（Windows 7 起的 Ribbon 版 mspaint）的 macOS 原生复刻。界面照原版的功能区（Ribbon）布局：“文件”按钮、主页、查看和使用文字工具时出现的“文本”选项卡，分组、命令和顺序取自解码出来的 `UIFILE_MSPAINT`；交互细节按反编译结果实现。纹理笔刷的纹理、图标和光标都是本项目自己绘制的，没有使用微软的资源。应用图标是本地的 Codex 按设计说明画的原创图案（蓝色圆角底、白纸、珊瑚色笔触和铅笔）。

## 下载

在 [Releases](https://github.com/InphinitiZ/Sketchpad/releases) 下载 `Sketchpad-<版本>.zip`，解压后把 Sketchpad 拖进“应用程序”文件夹。需要 macOS 14 或更新版本，Apple 芯片和 Intel 芯片的 Mac 都能用。

app 没有用 Apple 开发者证书签名和公证，第一次打开时 macOS 会拦下来：双击一次，在提示里点“完成”，再到“系统设置 > 隐私与安全性”页面底部点“仍要打开”。也可以在终端运行 `xattr -dr com.apple.quarantine /Applications/Sketchpad.app` 后直接打开。

## 构建

装了 Xcode：打开 `Sketchpad.xcodeproj`，运行 `Sketchpad` scheme。工程由 `project.yml` 生成，改了目标或文件结构后运行 `xcodegen generate`。

只有 Command Line Tools：

```sh
scripts/build-app.sh         # 生成 build/Sketchpad.app（只含本机架构）
scripts/package-release.sh   # 生成 Apple 芯片和 Intel 通用的 app，打包成 build/Sketchpad-<版本>.zip
scripts/test.sh              # 跑全部测试
```

`scripts/make-icon.sh` 从 `Artwork/AppIcon/render.swift` 重新渲染应用图标并生成 `Support/AppIcon.icns`（结果逐字节可复现）。

脚本会自动绕过两个 Command Line Tools 的问题：残留的旧版 `PackageDescription` 接口文件导致 manifest 链接失败，以及 SwiftPM 找不到 swift-testing 的宏插件。

## 结构

- `Sources/PaintCore`：像素模型和算法，不依赖 AppKit。`Bitmap` 是左上角原点的 RGBA8 位图，`Raster` 是铅笔、橡皮和油漆桶的硬边算法（含 Shift 方向锁定），`Shapes` 是 23 种形状的几何和绘制（含旋转/翻转方向），`Brushes` 是普通、书法和喷枪笔刷，`Media` 是 5 种纹理介质（笔刷、纹理轮廓和填充共用），`Selection` 是选区遮罩和浮动选区（移动、复制、拖尾、拉伸、反向），`Handles` 是手柄几何，`Transform` 是旋转、翻转、缩放、拉伸、倾斜和反色，`ImageCodec` 负责读写 PNG、JPEG、GIF、TIFF、HEIC 和读取 ICO（保留 DPI），`Bitmaps` 写四种颜色深度的 BMP。
- `Sources/Sketchpad`：AppKit 外壳。
  - 窗口：`CanvasWindowController`（布局、缩放、查看选项、编辑颜色、全屏）、`CanvasWindowController+Ribbon`（各选项卡和“文件”菜单）、`Ribbon`（功能区控件）、`RibbonIcons`（图标，刷子图标用笔刷引擎实时画出）、`ColorControls`（调色板和颜色块）、`StatusBar`（状态栏和缩放滑块）、`ToolCursors`（各工具的指针）、`MainMenu`（菜单栏）。
  - 画布：`CanvasWorkspace`（灰色工作区和手柄层）、`CanvasView`（鼠标、键盘、选区、文字）、`CanvasView+Handles`（选区、画布、文字框、形状的手柄拖动）、`CanvasView+Shapes`（曲线和多边形的多步点击，画完仍可编辑的形状）、`CanvasView+Editing`（剪贴板、裁剪、撤销）、`CanvasView+Image`（图像命令、调整大小和扭曲）、`KeyboardDrawing`（方向键加速、键盘移动指针、空格键当鼠标键）、`TextBox`（富文本文字框）。
  - 文档：`CanvasDocument`（读写、撤销、打印）、`CanvasDocument+Saving`（另存为某种格式）、`CanvasDocument+Sharing`（邮件、桌面背景）、`ImageProperties`（图像属性、打印视图、页面设置附加项）、`PrintPreview`（打印预览的分页和页面视图）、`DeviceImport`（扫描仪和照相机）、`Preferences`（跨启动保存的设置）、`Localization`。
- `Support/*.lproj`：字符串表。键就是英文原文，所以英文不需要表；`zh-Hans` 是简体中文，术语尽量与原版中文版一致。新增界面文字时用 `localized("…")` 包起来并补上中文，`LocalizationTests` 会检查有没有漏翻或多余的条目。
- `Tests/PaintCoreTests`：算法单元测试。
- `Tests/SketchpadTests`：用合成的鼠标、键盘事件驱动画布和窗口，覆盖选区、手柄、形状编辑、文字、颜色、缩放、文件格式、设置等行为。

## 和原版对齐的行为

依据对原版 mspaint.exe 的反编译分析：

- 油漆桶：精确颜色匹配，四连通，没有容差。
- 铅笔和橡皮：硬边方形笔头；橡皮涂的是颜色 2。
- 形状：全部 23 种，默认抗锯齿，轮廓画在拖拽框之内；轮廓和填充都可选无、纯色、蜡笔、记号笔、油画、自然铅笔、水彩；和原版一样，粗细小于 4 的纹理轮廓、记号笔轮廓和记号笔填充都画成纯色，填充纹理不旋转、不缩放，从形状外框左上角开始平铺。线条和曲线选“无轮廓”时仍按纯色画。左键拖拽时轮廓用颜色 1、填充用颜色 2，右键拖拽时两者对调。Shift 约束为 45° 或正方形。曲线：先拖出直线，再拖两次弯曲（第一次同时移动两个控制点）。多边形：拖出第一条边，之后每次点击加一个角，双击或点回起点闭合；切换工具时自动闭合，Esc 放弃。箭头、星形、标注和闪电的比例参照 Office 自选图形。
- 笔刷：普通笔刷按原版的圆形印章规则（奇数直径半径 (w−0.5)/2，偶数半径 w/2）沿线盖章，硬边；书法笔刷 1/2 是 45°/135° 斜笔尖扫过的平行四边形；喷枪每次在圆内随机放 10 个点，按住不动时每 50 ms 补喷一次（间隔是本项目定的）。
- 尺寸档位和默认值取自原版（`CPBApp::AddTools`、`InitializeAttributes`）：铅笔 1/2/3/4（默认 1）；刷子 1/3/5/8（默认 3）；两种书法笔刷 3/5/8/10，共用一个设置（默认 5）；喷枪 4/8/16/24（默认 8）；橡皮 4/6/8/10（默认 8）；油画、蜡笔、记号笔、水彩 8/16/30/40（默认 30）；自然铅笔 4/6/8/10（默认 4）；形状 1/3/5/8（默认 5）。
- 纹理笔刷（颜料刷、蜡笔、记号笔、普通铅笔、水彩笔刷）：按原版 PGS 骨架笔画的规则，纹理顺着笔画方向铺、横跨笔宽，只决定不透明度，颜色始终是纯色；同一笔自己交叉的地方会叠加加深，相邻的笔段不会。纹理图案是本项目用程序生成的，没有使用原版的纹理位图。
- 压感：和原版一样只有纹理笔刷响应，宽度 = 档位 + (压力 − ½)·k，油画和水彩 k = 20，蜡笔 k = 10；记号笔、自然铅笔以及铅笔、刷子、书法、喷枪、橡皮都不受压力影响。鼠标和触控板没有压力，宽度就是档位值。
- 撤销：只保存改动区域的快照，最多 50 步。
- 缩放：12.5% 到 800%，最近邻显示。
- 选区：矩形和自由选区；拖动时选区被“拿起”，原位置填颜色 2；透明选择打开时，选区里颜色 2 的像素不覆盖下面的画面。一次选区从选中到取消（包括移动、粘贴、删除）算一步撤销；选区还浮着时按撤销，选区回到原位。
- 粘贴：贴在可见区域左上角并保持选中；图片比画布大时画布自动扩大。裁剪把画布缩到选区大小。
- 文字：点击或拖出文字框，整框统一字体、字号（磅，按 96 dpi 换算成像素）、粗体、斜体、下划线，可选不透明背景（颜色 2）；点击画布其他位置或切换工具时写入位图，之后不能再编辑；Esc 放弃。
- 旋转和翻转：只有 90° 的倍数，逐像素搬移，不插值。有选区时只作用于选区，否则作用于整张图。
- 调整大小和倾斜：先缩放、再水平倾斜、再垂直倾斜，合为一步撤销。缩放按像素面积加权平均：缩小时混合，整数倍放大时等同最近邻，近似原版用的 GDI HALFTONE。倾斜是原版的整数剪切，偏移 = (k·10⁶ / T + 5) / 10，T = round(100000·cot θ)，角度限 ±89°；正角度水平倾斜时顶部右移，空出的区域填颜色 2。缩放按百分比限 1–500%、按像素限 1–99999，都是原版的限制。
- 查看：标尺、网格线、状态栏开关、缩略图浮窗（可点击或拖动定位）。网格线按原版 `CImgWnd::DrawGrid` 的规则：任何缩放比例都显示，打开时不改缩放；间距随缩放和单位变化（像素：≥400% 每 1 像素，200% 起 5，100% 起 10，50% 起 20，25% 起 50，10% 起 100，更小 200；英寸依次为 1、0.1、0.25、0.5、1、2、5；厘米依次为 1、0.25、0.5、1、2、5、10）；400% 起是不透明的 #808080/#C0C0C0 交替点线，以下是叠在图上的半透明点线（50% 黑与 25% #E8E8E8 交替）。
- 图像属性：显示上次保存时间、磁盘大小、分辨率；宽高可用英寸、厘米或像素，按图片自己的 DPI 换算；改尺寸是改画布，原图左上角不动，多出的地方填颜色 2；“黑白”按亮度阈值转换（具体阈值是假设），可以撤销。
- 打印：用系统的打印和页面设置面板；按 DPI 换算打印尺寸（96 DPI 时 1 像素 = 0.75 pt）。比纸大的图按先横后竖平铺到多页（AppKit 默认会把宽出来的部分裁掉）。
- 格式：可保存 PNG、JPEG、BMP、GIF、TIFF；ICO 只能打开（取其中最大的尺寸）。DPI 从文件读出并在保存时写回。
- 快捷键：S 选择，T 文字，P 铅笔，E 橡皮，B 填充，I 取色，Z 放大镜；Esc 取消正在拖拽的形状或取消选择；方向键移动选区（按住会加速），Delete 删除选区；⌘⇧X 裁剪；⌥⌘R 调整大小和倾斜（原版是 Ctrl+W，但 ⌘W 在 Mac 上是关闭窗口）；⌘E 图像属性；⌘R 标尺；⌘' 网格线（原版 Ctrl+G，但 ⌘G 在 Mac 上是查找下一个）；⌘P 打印，⇧⌘P 页面设置。
- 本地化：界面支持英文和简体中文，跟随系统语言；调色板颜色名称（工具提示和 VoiceOver 使用）是本项目自己起的。
- VoiceOver：工具按钮、下拉框和调色板色块都有名称；色块可以直接按下设为颜色 1，用“设为颜色 2”自定操作代替右键；画布会报出尺寸和当前工具；用字母快捷键切换工具时会朗读工具名。
- 获取图像：“文件 > 从扫描仪或照相机获取…”打开系统 ImageKit 的设备浏览器，每次扫描或下载的照片都作为一张未保存的新图打开；“文件 > 从 iPhone 或 iPad 导入”（连续互通相机）拍的照片或扫描件像粘贴一样放在画布上，保持选中。

## 第二轮对照原版补齐的行为

依据对原版命令表、对话框、提示文字和交互代码的逐项对照（`CTracker`、`CImgWnd`、`CShapeTool*`、`CTextTool`、`CColorGallerySite`、`CAppletZoomControl` 等）：

- 选区：8 个 5×5 手柄（#555555 边框），在选区外 2 像素；每个手柄周围 31 像素都能抓住，选区内部（离边 15 像素以上）拖动则是移动。拖手柄按最近邻拉伸（COLORONCOLOR），不能翻转、最小 1×1、不锁比例；拉伸不单独占一步撤销。⌥ 拖动复制（原版 Ctrl），Shift 拖动留下拖尾，选区最多拖到只剩边缘贴着画布。Esc 拖动中回到原位。右键选区或右键拖出选区弹出右键菜单（剪切、复制、粘贴 / 裁剪、全选、反向选择、删除 / 旋转、重新调整大小、反色）。Tab 依次选中手柄，方向键调整。S 键在矩形和自由选择之间切换。自由选择完成后和原版一样显示外框。
- 画布：右、下、右下 3 个手柄（只在画布外侧能抓到），拖动显示虚线框，状态栏实时显示尺寸，松开后改画布大小，新区域填颜色 2，Esc 取消。
- 形状：画完后保持可编辑，可拖动、用 8 个手柄缩放（最小 8 像素，不翻转），直线是两个端点手柄；改轮廓、填充、粗细或颜色立即重绘；旋转、翻转、反色作用于这个形状；Esc 或 Delete 丢弃，Return 提交（原版 Ctrl+Space，Mac 上被输入法占用），点别处提交并直接开始画新形状，切换工具也会提交。右键有形状菜单。Shift 画正方形取较短边，直线在 22.5° 内吸附到水平或垂直。多边形落点离起点 10 像素内即闭合。
- 文字：富文本，字体、字号、粗体、斜体、下划线、删除线和颜色作用于选中的文字；单击建立的框是原版的最小尺寸（约 20 个字符宽）；拖边框移动、拖手柄改大小；默认 11 磅（中文系统用苹方，原版用微软雅黑/Calibri）。格式菜单提供 ⌘B/⌘I/⌘U。
- 工具：橡皮擦右键只把颜色 1 替换成颜色 2；铅笔和刷子按住 Shift 锁定在起笔方向（0/45/90/135°）；取色器拖动时实时显示，松开后回到之前的工具；放大镜悬停显示预览框，点击放大到该区域；⌘[ / ⌘] 调整粗细（原版 Ctrl+-/+，有选区时把选区缩小一半/放大一倍）；⌘ 加滚轮缩放（原版 Ctrl+滚轮）。指针按工具变化，橡皮擦和刷子显示实际大小的轮廓。
- 颜色：颜色 1/颜色 2 是二选一按钮，点调色板设置当前那个，Shift+点击设置另一个；第三行 10 个自定义颜色，用“编辑颜色”加入（重复的移到最后，超过 10 个挤掉最早的）。
- 查看：缩放档位 12.5%–800%（含 500%、700%），缩放会先放下浮动选区；状态栏有指针位置、选区大小、画布大小、文件大小（未保存时“大小: 无”）和 −/滑块/+ 缩放控件，中点是 100%；缩略图开关打开后只在放大超过 100% 时显示；标尺标出指针位置；全屏（F11）任意键或点击退出。
- 文件：“文件”按钮菜单与原版相同（新建、打开、保存、另存为 ▸ PNG/JPEG/BMP/GIF/其他格式、打印 ▸、从扫描仪或照相机、在电子邮件中发送、设置为桌面背景 ▸ 填充/平铺/居中、属性、关于、退出、最近的图片）；标题栏有快速访问工具栏（保存、撤销、重做）。BMP 可存为单色、16 色、256 色、24 位；存 GIF 或低色深 BMP 会丢颜色时先提示。设为桌面背景前必须保存。拖进窗口的文件只打开第一个。可打开 HEIC。
- 图像属性和对话框：宽高 1–99999（过大时提示内存不足），单位记忆并同时用于标尺和状态栏；转为黑白前确认；“调整大小和扭曲”像素模式也允许 1–99999。页面设置可设居中和“调整为 N 页宽 × M 页高”。
- 崩溃恢复：原版通过 Windows 的应用恢复机制，在崩溃时把图存成恢复文件，重启后以“xxx (已恢复)”打开并标记为已修改，超过 2 小时的恢复数据作废（`PaintRecoveryCallback`、`RecoveryData::IsOld`）。Mac 上用 NSDocument 的“另存到别处”自动保存实现：有改动后每 15 秒（本项目定的间隔）把图无损存成 PNG 放进系统的自动保存目录；崩溃后重新打开 app，窗口恢复时载入这份副本，标题显示“xxx (已恢复)”并标记为已修改，保存后恢复标记消失；超过 2 小时的副本丢弃，改为打开上次保存的文件。自动保存不会提交正在编辑的文字框、选区或形状。
- 照片元数据：和原版 `LoadDIBGdiplus` 一样，打开 JPEG 时按 EXIF 方向标记把像素转正（HEIC 也照此处理）；和 `SaveDIBToFile` 一样，以原文件相同的格式保存时保留相机、拍摄时间、GPS、IPTC 等元数据，方向标记改为 1，并写入新的缩略图；换成别的格式保存则不保留，之后也不再带回。
- Ribbon 随窗口变窄：分组按原版 `UIFILE_MSPAINT` 里各分组的缩放顺序依次折叠成一个大按钮，点开在弹出框里显示整组控件。主页：剪贴板 → 图像 → 工具 → 形状；查看：缩放 → 显示或隐藏 → 显示；文本：剪贴板；打印预览：缩放。原版每个分组都有折叠用的图标，所以没有排顺序的分组（颜色、字体、背景、打印、预览）在这之后从右往左折叠（Windows Ribbon 的默认做法）；“刷子”“粗细”“关闭打印预览”本身就是一个按钮，不折叠。全部折叠后还放不下，或窗口小于 300×250（Windows Ribbon 的下限），整条 Ribbon 隐藏。缩放顺序是从编译后的 Ribbon 数据推断的，实际缩放由 Windows 的 Ribbon 框架完成，无法从 mspaint.exe 反编译核实。
- 打印预览：“文件 > 打印 > 打印预览”（菜单栏“文件 > 打印预览”）用预览页替换画布，Ribbon 只剩“打印预览”选项卡（打印：打印、页面设置；缩放：放大、缩小、一页、两页；预览：上一页、下一页；关闭打印预览），提示文字用原版的。行为照原版所用的 MFC `CPreviewView`：三档缩放（整页、实际大小、两倍），两页只在整页档显示；点页面放大一档并保持点击处不动，最大一档再点回到整页；“打印”先关闭预览再打印；PageUp/PageDown 翻页，整页档时方向键也翻页；Esc 关闭。页面设置改完立即刷新；预览中撤销也会刷新。分页、页边距、居中、缩放和“调整为 N 页”与实际打印一致（“调整为 N 页”现在按页边距以内的区域计算）。
- 键盘绘图（`CImgWnd::OnKeyDown`、`InputProcessor`、`VirtualCursor`）：没有选区或可编辑的形状时，方向键移动鼠标指针，空格键就是鼠标左键（按下、拖动、松开），所以每个工具都能只用键盘画。指针只在画布的可见部分里移动，离右边和下边留 2 点；指针在别处时，第一次按方向键先跳回上次键盘留下的位置。方向键的速度和原版一样：第一次按下立即移动 1；按住时每 10 毫秒移动一次，头 100 毫秒不动，之后从 1 线性加到 5，2 秒时到最快（原版 `Keyboard` 设置的默认值 1、5、100、2000，取自 `CPBApp` 构造函数）；Shift 加倍；按住 ⌥ 时改为滚动画布（原版是 Ctrl）。有选区、可编辑的形状或 Tab 选中的手柄时，方向键先移动它们，同样按这个速度。有选区时按 Return 把选区放到画布上，VoiceOver 会读出“已成功放置在画布上”（原版 Ctrl+Space）。画布的 VoiceOver 帮助里有原版的键盘用法说明（换成 Mac 的按键）。
- 记住的设置：标尺、网格线、状态栏、缩略图、单位、文字字体和效果、新建图片沿用上次画布尺寸（不超过 5000）、窗口位置。

### Mac 上有意不同的地方

- 快捷键用 ⌘ 代替 Ctrl；与 macOS 冲突的换了：调整大小和扭曲 ⌥⌘R（⌘W 是关闭），网格线 ⌘'（⌘G 是查找下一个），复制选区 ⌥ 拖动（Ctrl+点按是右键），提交形状和放置选区 Return（Ctrl+Space 切换输入法），键盘绘图时滚动画布 ⌥+方向键（⌃+方向键是切换桌面和调度中心），粗细 ⌘[ / ⌘]（⌘± 是缩放）。
- 菜单栏保留，Ribbon 控件用 macOS 外观；折叠后的分组用 NSPopover 弹出。
- 打开的图片会拼合到白底上，所以不会出现原版“透明度将丢失”的提示。
- 键盘绘图时，原版的空格键是系统级的鼠标按下，指针停在 Ribbon 上也会点下去；这里空格键只作用于画布，指针不在画面上时先跳回画布。
