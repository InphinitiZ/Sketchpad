# Sketchpad

经典画图的 macOS 原生移植，目前完成到第 3 阶段：全部 23 种形状、普通/书法/喷枪笔刷、标尺/网格/缩略图、图像属性、打印，以及 GIF/TIFF/ICO（名字是占位）。

## 构建

装了 Xcode：打开 `Sketchpad.xcodeproj`，运行 `Sketchpad` scheme。工程由 `project.yml` 生成，改了目标或文件结构后运行 `xcodegen generate`。

只有 Command Line Tools：

```sh
scripts/build-app.sh   # 生成 build/Sketchpad.app
scripts/test.sh        # 跑全部测试
```

脚本会自动绕过两个 Command Line Tools 的问题：残留的旧版 `PackageDescription` 接口文件导致 manifest 链接失败，以及 SwiftPM 找不到 swift-testing 的宏插件。

## 结构

- `Sources/PaintCore`：像素模型和算法，不依赖 AppKit。`Bitmap` 是左上角原点的 RGBA8 位图，`Raster` 是铅笔、橡皮和油漆桶的硬边算法，`Shapes` 是 23 种形状的几何和绘制，`Brushes` 是普通、书法和喷枪笔刷，`Selection` 是选区遮罩和浮动选区，`Transform` 是旋转、翻转、缩放和倾斜，`ImageCodec` 负责 PNG、JPEG、BMP、GIF、TIFF 读写和 ICO 读取（保留 DPI）。
- `Sources/Sketchpad`：AppKit 外壳。`CanvasDocument`（NSDocument，负责撤销）、`CanvasView`（画布、鼠标、选区和文字交互）、`CanvasView+Editing`（剪切、复制、粘贴、裁剪、撤销）、`CanvasView+Image`（图像菜单和“调整大小和倾斜”对话框）、`CanvasView+Shapes`（曲线和多边形的多步点击）、`ImageProperties`（图像属性对话框和打印视图）、`ThumbnailPanel`（缩略图窗口）、`TextBox`（文字工具的编辑框和栅格化）、`CanvasWindowController`（侧栏、缩放、状态栏）、`MainMenu`（代码构建的菜单栏）。
- `Tests/PaintCoreTests`：算法单元测试。
- `Tests/SketchpadTests`：用合成的鼠标事件驱动 `CanvasView`，以及文字栅格化的方向和位置测试。

## 和原版对齐的行为

依据《Windows 画图移植 macOS 分析》里的反编译结果：

- 油漆桶：精确颜色匹配，四连通，没有容差。
- 铅笔和橡皮：硬边方形笔头；橡皮涂的是颜色 2。
- 形状：全部 23 种，默认抗锯齿，轮廓画在拖拽框之内；轮廓可选“无/纯色”，填充可选“无/纯色”（纹理质感留到第 4 阶段）。左键拖拽时轮廓用颜色 1、填充用颜色 2，右键拖拽时两者对调。Shift 约束为 45° 或正方形。曲线：先拖出直线，再拖两次弯曲（第一次同时移动两个控制点）。多边形：拖出第一条边，之后每次点击加一个角，双击或点回起点闭合；切换工具时自动闭合，Esc 放弃。箭头、星形、标注和闪电的比例参照 Office 自选图形。
- 笔刷：普通笔刷按原版的圆形印章规则（奇数直径半径 (w−0.5)/2，偶数半径 w/2）沿线盖章，硬边；书法笔刷 1/2 是 45°/135° 斜笔尖扫过的平行四边形；喷枪每次在圆内随机放 10 个点，按住不动时每 50 ms 补喷一次（间隔是本项目定的）。笔刷和喷枪的尺寸档位是本项目定的。
- 撤销：只保存改动区域的快照，最多 50 步。
- 缩放：12.5% 到 800%，最近邻显示。
- 选区：矩形和自由选区；拖动时选区被“拿起”，原位置填颜色 2；透明选择打开时，选区里颜色 2 的像素不覆盖下面的画面。一次选区从选中到取消（包括移动、粘贴、删除）算一步撤销；选区还浮着时按撤销，选区回到原位。
- 粘贴：贴在可见区域左上角并保持选中；图片比画布大时画布自动扩大。裁剪把画布缩到选区大小。
- 文字：点击或拖出文字框，整框统一字体、字号（磅，按 96 dpi 换算成像素）、粗体、斜体、下划线，可选不透明背景（颜色 2）；点击画布其他位置或切换工具时写入位图，之后不能再编辑；Esc 放弃。
- 旋转和翻转：只有 90° 的倍数，逐像素搬移，不插值。有选区时只作用于选区，否则作用于整张图。
- 调整大小和倾斜：先缩放、再水平倾斜、再垂直倾斜，合为一步撤销。缩放按像素面积加权平均：缩小时混合，整数倍放大时等同最近邻，近似原版用的 GDI HALFTONE。倾斜是原版的整数剪切，偏移 = (k·10⁶ / T + 5) / 10，T = round(100000·cot θ)，角度限 ±89°；正角度水平倾斜时顶部右移，空出的区域填颜色 2。缩放上限 500% 是本项目自定的。
- 查看：标尺（像素单位）、网格线（缩放到 400% 及以上才显示，开启时自动放大到 400%，阈值是本项目定的）、状态栏开关、缩略图浮窗（可点击或拖动定位）。
- 图像属性：显示上次保存时间、磁盘大小、分辨率；宽高可用英寸、厘米或像素，按图片自己的 DPI 换算；改尺寸是改画布，原图左上角不动，多出的地方填颜色 2；“黑白”按亮度阈值转换（具体阈值是假设），可以撤销。
- 打印：用系统的打印和页面设置面板；按 DPI 换算打印尺寸（96 DPI 时 1 像素 = 0.75 pt）。
- 格式：可保存 PNG、JPEG、BMP、GIF、TIFF；ICO 只能打开（取其中最大的尺寸）。DPI 从文件读出并在保存时写回。
- 快捷键：S 选择，T 文字，P 铅笔，E 橡皮，B 填充，I 取色，Z 放大镜；Esc 取消正在拖拽的形状或取消选择；方向键逐像素移动选区，Delete 删除选区；⌘⇧X 裁剪；⌥⌘R 调整大小和倾斜（原版是 Ctrl+W，但 ⌘W 在 Mac 上是关闭窗口）；⌘E 图像属性；⌘R 标尺；⌘' 网格线（原版 Ctrl+G，但 ⌘G 在 Mac 上是查找下一个）；⌘P 打印，⇧⌘P 页面设置。
